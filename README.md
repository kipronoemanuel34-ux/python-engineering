# Python for Mechanical Enginering
Small programs I wrote while learning python, using engineering calculations.

## Programs
- engineerin1.py: Celsius to Fahrenheit converter
- engineering2.py : stress calculator (force/ area ) with a safe/unsafe check
- engineering4.py : rod stress check for steel, aluminium and copper using a safety factor
- engineering5.py : the same check, repeatable for many parts in one run

## Limitations
These are learning examples, not design tools. Real design checks many more things.
